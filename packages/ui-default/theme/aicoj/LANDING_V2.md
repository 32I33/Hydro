# AICOJ 访客首页改版说明（feat/homepage-ai-first）

## 设计目标

让访客在首屏回答三个问题：

1. **这是什么**：AICOJ 是带 AI 助教的在线编程判题系统（OJ）。
2. **对我有什么用**：写 C++ / Python、实时判题；代码未通过时，AI 结合代码与失败测试点定位错因并分层引导。
3. **下一步做什么**：登录 / 注册后开始刷题，或滚动查看三项 AI 能力。

## 新版信息架构

1. **首屏 Hero**：产品定位 + 双 CTA + 三项信任标记；右侧是「代码 → WA 测试点 → AI 行级诊断 → 分层提示」的真实产品示例。
2. **核心 AI 能力**：提交后行级诊断、三层引导对话助教、AI 成长档案与薄弱点复盘。
3. **信任原则横条**：引导不代写、证据可核对、结论可申诉、Hydro 权威判题。
4. **完整 OJ 能力**：深色静态网格展示题库、训练、比赛、功课；取消横向滚动劫持。
5. **底部 CTA**：明确回到登录 / 注册动作。

## 删除的旧内容

- 「先别急着要答案 / 思考室」三屏叠纸段（`axl-story`）。
- 「一章一章走到下一道题」纵向滚动驱动横向时间线（`axl-timeline`）。
- 首屏抽象学习桌便签和 3000px 滚动占位。

## UX 约定

- 不请求 Google Fonts 等境外资源，全部使用站内置字体、SVG 和系统字体。
- 首屏内容默认可见；IntersectionObserver 只负责渐进揭示，不依赖 JS 才能阅读。
- Hero 示例提供三步切换，按钮支持键盘、清晰焦点、状态文本和 `aria-pressed`；不自动轮播，不抢用户操作。
- 滚动锚点补偿导航栏高度；支持 `prefers-reduced-motion`，减少动画时不自动平滑滚动。
- 卡片 hover 使用短距离像素位移；移动设备不依赖 hover 才能访问任何功能。
- 手机端 Hero、AI 卡、OJ 卡均单列；代码与诊断可以阅读，不出现横向页面滚动。
- 所有真实入口沿用未登录跳登录并携带 redirect 的规则。

## 当前部署边界

此分支用于本地验证。曼谷服务器恢复前，不以“线上已更新”表述；上线必须单独执行模板 / 静态资源同步和 `oj-backend` 重启，并验证首页及 `/login` 均返回 200。
